# 记忆星海样式参考

用户于 2026-10-31 指定：https://github.com/asdfd3/3d-memory-sea 。
参考提交：bcc1bb6b7e9e8b3dc4cf16b649a94445c8b6f25f，MIT。

采用其 Canvas 三维透视、星尘、星团、节点光晕、浮层和轨道/平移/缩放交互方向；用 React 组件承载，事件限定到组件画布，卸载取消绘制，默认关闭动态漂移。

两个模式使用应用自己的 Wiki 与记忆数据。保留 Wiki 图谱分析工具；记忆分类不采用参考项目的经历/心情/事实等类别，等待用户提供的分类方案。参考代码及许可位置见根目录 THIRD_PARTY_NOTICES.md。
