# C09 统一服务端授权

主程序和 HTTP 工厂均要求账号认证，初始化密钥不再有数据访问通道。人员使用 Cookie，Agent 使用 Bearer kwt_；失败时不回退到另一种凭据。客户端提供的账号/角色头或工具参数不能代替 AccessContext。

所有共享资源经 service-api 的 guarded repository：每次读取/写入重查凭据、成员、角色及显式委托；下游上传、检索、CLI/MCP 和任务执行端口获得同一个受保护仓储。项目创建与创建者 manager 成员同一 SQLite 事务，管理员不自动读取未加入的项目，分页不返回不可见项目。

| 接口 | 服务端要求 |
| --- | --- |
| 项目读取/事件 | project.read；事件还按资源读取权限过滤 |
| Wiki 列表/正文、关键词检索 | wiki.read |
| Wiki 保存/删除 | wiki.write，原版本前提仍强制 |
| 文档目录/内容 | documents.read |
| 上传并登记 | documents.write；上传后、元数据提交前再次检查 |
| 工作区读取 | project.read；记忆及关联按可见性过滤 |
| 工作区保存 | memory.write 或 domains.manage，再按实际差异检查操作和每条记忆 |
| 成员/工作角色管理 | members.manage / roles.manage |
| 账号管理 | 真实人员 admin；借用身份不能成为全局 admin |
| 任务执行入口 | tasks.manage；执行端口、检查点、结果回传再次检查 |
| 本机执行连接器入口 | agent.run；无共享执行器时 501 |
| CLI/MCP 资源工具 | 与直接资源 API 相同，工具名称白名单，禁止任意 Shell 字符串解释 |

## 运行上下文

任务若未显式选上下文，启动时也会保存一个上下文。执行器获得不可变 context、检查点 check 和限定项目的资源仓储；不能持有原始仓储或绕过授权层。新角色切换不修改旧执行，旧上下文不会继承后授操作。凭据/委托/角色撤销会使后续检查点、写入和结果交付失败。SSE 每次持久事件轮询同样重查，退出/吊销后关闭连接。

当前共享任务/本机 CLI 执行器仍待 H/I 系列接入；C09 实现授权网关和端口，默认不配置执行器，返回 501。未复制 Rust Agent 引擎、未开放远程任意 Shell，也未宣称强持久任务完成。本地独立桌面/旧 loopback MCP 仍属于 C01 的本机操作系统信任域，不暗中接入或同步共享数据；共享 MCP 使用独立入口，绝不回退到旧本机 API。

## 记忆权限基础

MemoryRecord 可选 access 字段：visibility 为 project/role/private，ownerId 为稳定身份，role 还需 workRoleIds。旧记录没有 access 时按项目共享处理；这是访问元数据，不是用户尚待补充的记忆分类。角色记忆须匹配当前获授工作角色，管理员没有隐式绕过。私有记忆由真实所有者访问，其他真实操作者需要匹配记忆/所有者/账号/操作且未过期的显式授权；借用所有者身份不会自动获得私有读取权。

GET 工作区会隐藏不可见记忆及关联；PUT 按可见基线合并，保留不可见记录和边，拒绝猜测隐藏 ID、越权修改/删除、伪造所有者及扩大可见范围。领域变更单独要求 domains.manage。只有真实所有者能通过 /memories/:id/grants 发放/吊销私有授权。更完整记忆分类、审核/合并/检索与星图属于 F/G 系列。

数据库 schema 6 增加私有授权，保留旧库。升级时已有 C04 admin 元数据但没有密码，可用初始化密钥给相同 handle 建立首次口令，稳定 ID/成员关系保留；一旦任一 admin 已有密码，初始化关闭。

## 验证入口

server/authorization.test.ts 使用真实 HTTP/SQLite，覆盖跨项目、只读写入、CLI/MCP/检索、私有与角色可见性、合并保留隐藏记录、真实所有者授权、执行中撤权和事件流失效。analysis/implementation/smoke-shared-clients.mjs 启动独立构建产物，运行真正 CLI 子进程和 MCP stdio 握手/调用/撤销，凭据和数据均临时生成并清理。

## C10 界面与审计

共享 Web 已提供首位管理员设置、Cookie 登录/恢复/退出、改密、账号/成员/角色/Token/委托管理和身份切换。切换列表来自服务端有效授权，界面展示真实与有效身份，未保存 Wiki 支持取消切换；只读权限禁用写控件，仍以服务端校验为准。

schema 7 审计保存请求前 pending 和完成后的结果/身份/上下文引用；查询支持项目/本人/全局安全范围、结果/操作者过滤与游标。普通成员只能查询自己的项目记录；项目管理权限可读该项目，全局 admin 不能从全局日志读取未加入项目的审计。动作路径只保留白名单路由词，不保存原始 ID 路径、查询或正文、口令、Token。审计与资源事务不同，崩溃时可留下 pending；防篡改归档和保留策略仍在后续运维范围。

人员会话负责签发身份委托；Agent Token 可以使用已获授的角色/委托，但不能签发持久委托，以免短期凭据留下超期权限。Bearer Token 的凭据管理只允许查看/吊销自身，不能操作同一 Agent 的其他 Token（包括其他项目）。
