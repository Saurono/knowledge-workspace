# D04 来源入口与时间验收矩阵

更新日期：2026-11-09，Asia/Shanghai。本表描述实现边界，未通过的场景不等同于完成；最终原生产物证据另见 d09-native-evidence-20261108.md。

| 入口 | 来源接收证据 | 编译与时间边界 | 当前验收限制 |
| --- | --- | --- | --- |
| 本地文件/目录导入 | source-lifecycle 在实际复制后 confirmImportedSource；失败保留预留身份 | 队列进入 autoIngest，解析文本修订与原始文件 SHA 分开 | D02 回归与 D09 临时真实文件生产链；模型使用确定性 fixture |
| 来源目录观察/定时扫描 | registerObservedSourcePaths 记录首次观察，不能推断文件创建时间 | 使用同一来源稳定 ID 和队列入口 | 原生 watcher 与定时真实触发尚需 D09 |
| URL 下载 | 下载成功写入后确认；原 URL 作为来源；重试沿既有路径 | 同 URL 不因标题变化重复登记；失败不报编译完成 | URL 入口合成传输回归已覆盖；真实网络提供者不是本次完成依据 |
| 来源页手动编译 | 复用已登记来源，不重新赋首次时间 | enqueueSourceIngest；缓存证据不回填历史未知首次时间 | 页面/时间投影回归；生产链重跑保留首次时间 |
| 共享 Web/HTTP/CLI/MCP 上传 | 受保护上传记录服务接收时间及原始字节修订 | 仅接收不代表 parse/compile/index 成功；无证据显示未知 | 共享服务与浏览器回归；共享编译执行器不因本系列自动宣称存在 |
| 聊天生成 Wiki 后再次编译 | 先保存真实 Wiki，再登记 generated-wiki 来源；不复制到 raw | enqueueSavedGeneratedWikiQuery 经真实队列先绑定 sourceId，解析后绑定 revision/key；项目切换拒绝迟到入列 | helper/队列/保存后失败回归通过；排队失败保留页面并提示，raw 接收时间不冒用 |
| Wiki 编辑/生成/历史恢复 | Wiki 创建时间由共同写入边界维护 | 首次创建值保留；旧未知继续未知；恢复不标今天新建 | D04a 已完成；来源首次时间取 source catalog，当前修订取 receipt |

来源首次入库、当前修订首次入库和 Wiki 创建时间分别有独立证据。监听时间只表示系统第一次观察；服务资源 createdAt 只表示服务资源创建。索引重试、移动及恢复不得把这些字段重置为当前时间。

旧资料的来源首次接收时间仍为 `null` 时，本次执行可以用真实文件存在与原始字节 SHA 证明“本次接收验证/观察”。该执行检查点的开始时间表示当前操作，不能反向写入来源历史 `receivedAt`。回执的来源时间字段继续为未知，避免以缺历史日期为由禁止旧资料正常解析或偷偷关闭其索引策略。
