# D 系列整体交付边界

日期：2026-11-06（Asia/Shanghai）。用户授权将 D01–D09 全部完成；本文件取代先前 D05 仅设计的执行限制，不取代真实证据要求。主控定契约、调度、审查、验收和提交，Luna 编写程序、测试及工作流。

## 依赖与验收

- D03：本地来源树、Wiki 导航、检索、共享 Web 使用相同领域契约；稳定来源跨修订继承分类；授权在服务端；真实界面操作、项目切换、删除领域与 CAS 冲突验证。
- D04：真实复制/下载/上传后确认 received；可信编译落盘后确认首次及修订入库。生成 Wiki 二次编译不能伪装 raw source 接收。历史未知时间不回填，恢复/移动不改首次值。列出实际全部入口矩阵。
- D05：复用原生 LanceDB 索引，不以 mock 端口当实际提交。每页绑定内容/配置指纹、准确 chunks 及向量摘要，提交后读回、持久清单成功才有证据。来源多页汇总必须全部核验；旧 attempt、变更输出或配置不能沿用旧成功。索引失败单独重试，保留编译和首次时间。
- D06：兼容旧独立 JSON 回执，新增各阶段检查点、结构化错误、输出修订及索引证据。来源/任务/attempt 固定，未知保持未知。投递状态与业务阶段状态分离。
- D07：仅写 kb-ingest-records 独立 JSON，不修改源笔记。断连 pending、明确重试与自动同步；已发送快照有变化仍须重新投递，原子写入后读回核验。来源移动/重命名沿稳定 ID；回执目录在所有监听/定时导入路径排除，防循环。
- D08：Web 不直接获得任意本机路径/文件权限。本机连接器显式启动并选择临时或用户指定 Vault，配对授权绑定浏览器 Origin、服务地址、项目、Vault 和时效；最小权限只交付独立回执，撤销后立即拒绝。凭据不进 URL/日志/仓库，不从网页任意路径写文件；界面展示连接、过期、断连及待重试状态。
- D09：使用合成真实文件和独立临时 Vault，保存原笔记 hash，证明不变；执行原生索引、外部读取 JSON、断连恢复、移动/重命名、防循环及撤销。原生程序须对应当前提交，已安装旧程序只能用于探测环境。真实模型与确定性合成模型提供者分开标记，不混称生产模型验收。

## 交付纪律

每个可审查节点冻结后主控检查真实 diff、类型、边界/审计及适当集成测试；最终运行完整回归、构建、共享浏览器/CLI/MCP和三平台 CI。D05 Rust 测试须实际执行，不能仅 cargo build。D09 环境未通过时保持未完成，不以文档、注入或旧安装程序替代。
