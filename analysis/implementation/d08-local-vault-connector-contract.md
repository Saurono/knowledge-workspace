# D08 Web 到本机 Vault 连接契约

日期：2026-11-06。作为 D 系列授权范围的实现任务书，未实现内容不得标为已完成。

## 信任与连接

连接器作为用户显式启动的独立本机进程，仅绑定 127.0.0.1。启动参数固定允许的 Web Origin、共享服务地址、projectId 与用户选择的 Vault；这些绑定不能由网页请求覆盖。本机路径不从网页 payload 提供。Vault 必须为真实目录并含 .obsidian；回执输出目录固定 kb-ingest-records。

启动时生成一次性高熵配对码（短时有效、有限次尝试），只在用户本机控制台显示。Web 显式填写配对码，Origin 必须精确匹配，交换随机会话 token；token 只保存在界面内存，不进 URL、本地持久存储、审计和正文日志。会话绑定 Origin、服务/project、Vault、到期时间。提供状态与撤销接口；过期/撤销/Origin 错误立即拒绝。拒绝非 loopback Host，CORS 不允许通配，预检同样受 Origin/Host 限制。

## 最小写入能力

网页只能请求同步已经存在且有权读取的独立回执，不得传任意文件名、目录或可执行动作。连接器使用本机配置的服务凭据（环境或受保护配置，绝不由网页展示）读取受保护项目回执；每次重新验证共享服务授权。文件名只由已校验的稳定 source/revision/receipt ID 生成，拒绝路径穿越和未知 schema。只写独立 JSON，原子落盘后读回校验；不修改或自动导入任何 Vault 笔记。

同一回执版本重复同步幂等；payload 变化须重新交付并记录摘要。断连或撤权保持明确失败/待重试，不回报 delivered。撤销会话后不允许迟到请求完成写入。限定请求体、超时、并发与配对速率，返回错误不包含 token 或本机秘密。

## 界面与验收

Web 显式连接、显示项目绑定与状态、到期/断连/待重试、同步与撤销；没有本机进程时给可执行启动说明。不得使用 iframe/外链偷偷启动原生动作。

用真实 loopback HTTP、临时共享服务与独立 Vault 验证配对、错误 Origin/Host/码/过期/撤销/跨项目、服务运行中撤权、独立 JSON 可读取与源笔记 hash 不变。HTTPS 网页对 loopback 请求的浏览器策略必须实际验证，不以服务单测替代；失败时保持明确 unsupported 并提供显式本机 pull 同步路径，不降级成任意 CORS。
