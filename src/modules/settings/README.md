# 设置与模型路由

领域层拥有模型/搜索/解析/代理/导入等设置类型、语言选项、提供商预设、预设合成、任务/项目模型路由、推理能力与 Azure 地址策略。Store 保留类型兼容导出和界面状态，不再定义这些业务模型；向量配置仍由 retrieval 拥有。

`application/configuration` 经类型化键值仓储端口读写原 app-state.json 键，保留项目模型覆盖与自定义预设串行队列、失败后恢复、原配置规范化、旧全局定时导入迁移及显式 save 行为。`app/settings` 注入 Tauri Store、来源监听规范化、路径与缩放策略；模型路由一次捕获当前 Store 快照。旧 lib/project-store 与组件中的 preset 文件保留兼容重导出。

平台能力服务区分 desktop/web/preview；预览能力标为 simulated，桌面 CLI 安装状态仍需单独探测，Web 未连接桥接时不声称拥有本机能力。关于页显示当前运行环境。能力可用性不是用户权限、CLI 登录或 Vault 健康检查；sharedApi 未验收时维持 unknown。

当前保持旧设置持久化方式，不把凭据存储改为密钥库，也不新增生产 Web 配置后端。端口测试覆盖项目覆盖更新串行、失败恢复和环境能力区分，旧测试继续覆盖持久键名、预设/路由及推理规则。
